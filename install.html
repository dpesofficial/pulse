Reads the things a public scan cannot see: real plugin versions, pending updates, core version, PHP, admin accounts, spam. No password, no setup per site.

Drag this to your bookmarks bar. Already have one? Delete it first, a bookmarklet is a snapshot of the code from when you dragged it.

⚡ WP Pulse

Using it

  1. Log into any client's wp-admin, as you normally would.
  2. Click ⚡ WP Pulse in your bookmarks bar. Any admin screen works.
  3. It reads every screen it needs and copies the result.
  4. Switch back to WP Pulse and press Ctrl+V. The unknown rows fill in.

What it does to the site

Nothing. Every request is a GET to a fixed admin page with no action parameter. It never submits a form, clicks a button, follows a link, or writes anything. It reads the screens you would have opened yourself, then gets out of the way.

Source is right here: collect.js. Read it before you trust it.

If nothing happens when you click it: the site has a Content-Security-Policy that blocks bookmarklets. Uncommon on WordPress, but some hardening plugins add one. Nothing to fix, use Copy for Claude on that site instead.

It cannot run on a schedule. It needs your click. Overnight checks across many sites would need Application Passwords, which is a different build.
